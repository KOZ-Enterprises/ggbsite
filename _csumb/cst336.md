<h2>Final Project: Culinary Otter</h2>
<figure><a href="https://culinaryotter.garygigabytes.com/" target="_blank">
    <img src="/assets/imgs/culinaryotter.png" alt="Culinary Otter Web Application" title="Culinary Otter Web Application"></a>
    
</figure>
<p>Culinary Otter is a user-friendly web application designed for students and home cooks seeking culinary inspiration. It allows users to:</p>
<ul>
    <li class="bullet"><strong>Search for recipes</strong> using an external database.</li>
    <li class="bullet"><strong>View recipe details</strong>, including ingredients and instructions.</li>
    <li class="bullet"><strong>Create user accounts</strong> to save favorite recipes.</li>
    <li class="bullet"><strong>Create customized recipes</strong> from recipe lists.</li>
    <li class="bullet"><strong>Manage personalized lists</strong> of favorite recipes.</li>
    <li class="bullet"><strong>Retrieve saved recipes</strong> for later use.</li>
    <li class="bullet"><strong>Enjoy food images</strong> provided via an external API.</li>
</ul>
<p>The project combines a robust backend, external APIs, and a polished front end to deliver a seamless culinary experience.</p>
