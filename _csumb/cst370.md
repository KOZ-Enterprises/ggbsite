<h3>Project Summary: All-Pairs Shortest Path (Floyd–Warshall Algorithm)</h3>

<p>This project focused on implementing the Floyd–Warshall algorithm to compute all-pairs shortest paths in a weighted directed graph. The program reads an adjacency matrix with up to 25 vertices, handles infinite distances, and produces the final distance matrix representing the shortest paths between all vertex pairs.</p>

<p><strong>Key points:</strong></p>

<ul>
    <li>Implemented the Floyd–Warshall dynamic programming algorithm in Java.</li>
    <li>Processed adjacency matrices with support for infinite edge weights.</li>
    <li>Computed and displayed the final distance matrix D(n) after iterative relaxation.</li>
    <li>Applied formal time complexity analysis using Big O notation (O(n³)).</li>
    <li>Validated correctness using multiple sample test cases.</li>
</ul>

<p><strong>Additional Topics Covered:</strong></p>

<ul>
    <li>Sorting algorithms: Selection Sort, Bubble Sort, Insertion Sort, Merge Sort, Heap Sort, and Quick Sort.</li>
    <li>Graph traversal: Depth-First Search (DFS) and Breadth-First Search (BFS).</li>
    <li>Shortest path algorithms: Dijkstra’s Algorithm and Floyd–Warshall Algorithm.</li>
    <li>Minimum spanning trees: Prim’s Algorithm.</li>
    <li>Algorithm design paradigms: Decrease-and-Conquer, Divide-and-Conquer, Transform-and-Conquer.</li>
    <li>Formal runtime analysis using Big O, Big Theta, and Big Omega notations.</li>
</ul>
