network studies including certificate programs. Includes hands-on networking labs that incorporate Cisco CCNA lab
components.

<h3>Multi-Router Virtual Network and Group Chat Application</h3>

<p>In this project, I designed and implemented a multi-router virtual network using Mininet and extended a custom socket-based chat application to support real-time group communication. I built a legacy-style network topology with multiple subnets and routers, assigned IP addresses and static routes, and verified full end-to-end connectivity across all hosts using automated testing. I then upgraded a two-client chat system into a three-client group chat service, deployed the server and clients across different network hosts, and programmatically launched them within the Mininet environment. This project demonstrates my ability to work with low-level networking concepts, routing, distributed systems, and networked application development. A video showcasing the fully working system is shown below.</p>
