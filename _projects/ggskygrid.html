The projects behind the path

Ground foundation

ggGridRunner

A four-wheel-steering rover for learning motor control, sensing, a reliable remote link and eventually navigation.

Shared planning core

ggChoreo

The code that assigns formation slots, plans trajectories and checks separation and dynamic limits. Version 1 is built. Flight validation is the next bridge between plans and hardware.

Coordinated autonomy

ggSwarm

A completed simulation capstone and a future physical research program. The next direction starts with checked trajectories, then adds online replanning behind a safety filter.

Optional flight-control branch

ggSkybit

A custom quadcopter and flight-controller learning project. It is a separate exploration, not a prerequisite for Crazyflie flights or swarm research.

Later application

ggSkylight

A possible outdoor light-show application of the planning and operating experience. Its business scope is still open. Indoor experiments do not establish readiness to run an outdoor show.

What comes next

The immediate target is a repeatable motor test on ggGridRunner. As stages finish, their project pages will carry the build notes, logs and videos. This page keeps the connections visible.

Outdoor ArduPilot work comes later. Custom flight control, more aircraft and show operations each need a reason to become the next project.
