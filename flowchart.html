Journey to Drone Swarm Light Shows
Phase 1: Prototype Remote Control System
  • Build a wireless controller using PS4 controller, Arduino, XBee radio, and OLED screen.
  • Establish a standard protocol for sending commands and receiving telemetry.
Phase 2: Rover Teleoperation (PS4)
  • Test remote control on a simple rover using the new wireless system.
  • Verify reliable two-way communication and refine command handling.
Phase 3: Mesh Networking & Range Testing
  • Experiment with XBee mesh networking to extend control range.
  • Assess communication reliability with multiple nodes in real-world conditions.
↓
Phase 4: Swarm Controller Development
  • Expand system to support controlling multiple drones or vehicles.
  • Add synchronized command features and group coordination logic.
Phase 5: Integration with Flight Controllers (ArduPilot)
  • Upgrade to professional-grade flight controllers for advanced features.
  • Integrate command and telemetry protocols with ArduPilot systems.
Phase 6: Drone Swarm Simulation
  • Simulate swarm coordination and light show choreography in software.
  • Test and refine group commands and synchronization logic before live tests.
↓
Phase 7: Live Swarm Light Show
  • Deploy multiple drones for a live, synchronized light show.
  • Showcase complete system integration with real-world choreography.
