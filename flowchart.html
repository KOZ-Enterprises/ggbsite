Journey to Drone Swarm Light Shows
📍 Current Phase: 1 of 9 – In Progress
Timeline: July 2025 → June 2026
🎓 Phases 7–8 will be executed as part of my CSUMB Capstone Project (proof-of-concept swarm)
Phase 1: Prototype Remote Control System
ECD July 2025
  • Build a wireless controller using DualShock4, Arduino, XBee radio, and OLED screen.
  • Establish a standard protocol for sending commands and receiving telemetry.
Phase 2: Rover Teleoperation (DualShock4)
ECD August 2025
  • Test remote control on a simple rover using the new wireless system.
  • Verify reliable two-way communication and refine command handling.
Phase 3: Mesh Networking & Range Testing
ECD September 2025
  • Experiment with XBee mesh networking to extend control range.
  • Assess communication reliability with multiple nodes in real-world conditions.
Phase 4: Swarm Controller Development
ECD October 2025
  • Expand system to support controlling multiple vehicles.
  • Add synchronized command features and basic group coordination.
Phase 5: Replace BlackPill with ArduPilot Board
ECD Mid-October 2025
  • Swap out the STM32 BlackPill for an ArduPilot-compatible flight controller on the rover.
  • Ensure compatibility with future drone and ROS2-based architecture.
Phase 6: Single Drone Integration (DS4 + ArduPilot)
ECD December 2025
  • Control a single quadcopter with ArduPilot using the existing DualShock4 input system.
  • Prepare ROS2-compatible pipeline for swarm expansion.
Phase 7: Drone Swarm Simulation
ECD January–March 2026
  • Simulate swarm coordination and light show choreography in software.
  • Develop synchronization, choreography, and ROS2 control logic for multiple drones.
Phase 8: Proof-of-Concept Swarm Light Show (3 drones)
ECD April–May 2026
  • Deploy a minimum 3-drone light show to demonstrate end-to-end functionality.
  • Serve as the core deliverable for the CSUMB Capstone Project.
Phase 9: Full Swarm Show (Post-Capstone)
Target: June 2026+
  • Scale up to more drones for a larger, synchronized light show performance.
  • Focus on polish, safety, and visual quality for a real audience experience.
