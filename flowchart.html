Journey to Drone Swarm Light Shows
📍 Current Phase: 1 of 9 – In Progress
Timeline: July 2025 → June 2026
🎓 Phases 7–8 will be executed as part of my CSUMB Capstone Project (proof-of-concept swarm)
Phase 1: Prototype Remote Control System
ECD July 2025
  • Use a DualShock4 controller with Arduino and XBee radio for wireless communication.
  • Display basic telemetry on an OLED screen using an Arduino Pro Micro.
Phase 2: Rover Teleoperation (DualShock4)
ECD August 2025
  • Wirelessly control a rover with the STM32 BlackPill MCU via the PS4 controller and XBee.
  • Verify control fidelity and develop telemetry feedback for closed-loop control.
Phase 3: Mesh Networking & Range Testing
ECD September 2025
  • Implement a basic XBee mesh for extended control range and reliability.
  • Test real-world performance with multiple nodes on various terrain layouts.
Phase 4: Swarm Controller Development
ECD October 2025
  • Create code architecture for managing multiple vehicles via shared commands.
  • Integrate early versions of open-source light show software (Skybrush).
Phase 5: Replace BlackPill with ArduPilot Board
ECD Mid-October 2025
  • Switch from STM32 BlackPill to an ArduPilot-compatible flight controller (e.g., Matek H743).
  • Confirm compatibility with MAVLink, RC input, and future ROS2 integration.
Phase 6: Single Drone Integration (DS4 + ArduPilot)
ECD December 2025
  • Use the same DS4-based control interface to fly a single quadcopter via ArduPilot.
  • Begin refining ROS2 pipelines and light show commands.
Phase 7: Drone Swarm Simulation
ECD January–March 2026
  • Use Skybrush and ROS2 to simulate swarm flight logic and choreography.
  • Implement synchronization and position tracking logic for simulated drones.
Phase 8: Proof-of-Concept Swarm Light Show (3 drones)
ECD April–May 2026
  • Fly at least 3 real drones in a coordinated light show using Skybrush and ArduPilot.
  • Record and present results as the final deliverable of the CSUMB Capstone Project.
Phase 9: Full Swarm Show (Post-Capstone)
Target: June 2026+
  • Expand to a larger drone fleet using scaled versions of hardware/software stack.
  • Refine light show choreography, safety protocols, and public demo logistics.
