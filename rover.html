Rover

Rover is a smart RC car built from scratch with the goal of adding autonomy using sensors and embedded hardware.

Project Overview

  • Status: In Progress
  • Objective: Develop a rover with wireless control and eventually autonomous navigation.
  • Technologies Used: Arduino, XBee, PS4 Controller, DRV8871 Motor Drivers, C++, 3D Printing

Resources

  • GitHub Project Page

Reflection

Rover has taught me about wireless communication, embedded motor control, and practical hardware debugging. It's also helping lay the foundation for future robotics projects.
